Choose a language in Studio

Use a session language override when an untitled file or unusual extension needs a known syntax language.

  1. Open the source tab and choose Document language in the editor actions.
  2. Choose a language, then press Apply to this document.
  3. Inspect the editor display. The captured tab keeps its identity even if you switched tabs while the form was open.
  4. To restore automatic filename detection, press Use filename detection.

The language choice does not modify or save the source. It keeps selection, pending edits and Undo/Redo history. It remains through normal edits and Save As, then expires when the document closes. Closing the form without applying changes nothing.

Language-aware comments and new language-service requests use this identity. Choosing a language does not install a compiler, syntax definition or language server. Existing live diagnostics may stop when their captured language no longer matches; restart them explicitly for the new language.

Read-only documents may change display language. If the document closed or its filename or policy changed elsewhere, reopen the form. Finish other active source reviews before applying a new language.

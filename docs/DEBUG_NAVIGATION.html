Source and Disassembly Navigation in Umicom Studio

Studio can reuse Framework's debugger navigation snapshot when a frontend needs to keep a stack frame, source line and machine instruction in context.

Read the selected location

UmiStudioDebugNavigationSnapshot location;
UmiStatus status =
    umi_studio_debug_navigation_snapshot(debugger, &location);

The returned value is a copy. Studio does not retain private debugger pointers and does not duplicate DAP parsing.

Follow a machine instruction

A frontend may select a retained disassembly row with umi_studio_debug_navigation_select_instruction(). If that instruction contains source correlation, the snapshot includes its source file and line.

Follow a source line

umi_studio_debug_navigation_follow_source() selects a matching instruction already in the current disassembly window. This makes it suitable for a future source-editor action without coupling the Framework service to GTK4.

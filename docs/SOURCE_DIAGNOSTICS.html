Source diagnostics in Studio

Use related diagnostic source navigation to inspect the other declarations or locations referenced by a message.

This guide describes the default notification mode. For a server that requires a request, follow explicit pull diagnostics and select that option in Problems.

Use Problems to inspect errors, warnings and hints from a local language server without changing the document. This source inspection is separate from a compiler build.

  1. Open a source document. Unsaved text and read-only drafts are supported.
  2. Choose Problems… in the editor toolbar.
  3. Enter the installed language server's absolute path, its arguments and the absolute project folder, or load saved settings for this language. Keep credentials out of executable arguments.
  4. Choose Capture source diagnostics. The chosen local server receives the complete captured draft and may read the project folder. Opening the form alone does not launch it.
  5. Select a result and read the full message, code, source and related locations. Explanation addresses remain plain text.
  6. Choose the reported range or a related destination in Source location to open, then choose Open reported range. Navigation preserves draft text and does not edit or save it.

The temporary connection returns its first matching publication and then closes. An empty result does not prove the project builds or that background analysis has finished. This action does not maintain continuous diagnostics or synchronize other unsaved documents.

If the source or selection changes, close and capture again. Changing server settings retires the old result. A server that supplies diagnostics only through pull requests can time out here. For a C or C++ server, inspect its compilation database configuration if includes or compile options are missing.

Ranges are checked against the exact captured text. Columns shown in diagnostic details count UTF-16 units; the end is excluded. Invalid coordinates are reported instead of rounded. Large source messages and slow startup can exceed the connection limits.

Open an indexed workspace file

Quick Open finds a filename or relative path in the current workspace index. An index is the file list shared with Explorer. Searching this list does not scan disk again, search file contents, save your current draft or send filenames to a provider.

  1. Open a workspace folder. Use Explorer → Refresh when files have been added or removed outside Studio, and wait for that refresh to finish.
  2. Press Ctrl+P, or select Quick Open… in the editor toolbar. Command search remains Ctrl+Shift+P.
  3. Type part of a filename or relative path, such as main.c or src/main. Matching is literal, with ASCII letters matched without case. Other Unicode text is matched exactly; this is not fuzzy search or a regular expression.
  4. Wait for the result list to update. The status shows how many indexed files match and the current workspace root. Each page has up to 64 complete file records; Next and Previous move through the matching list.
  5. Select a row and choose Open selected, or double-click the row. Enter in the query opens the selected result after filtering has completed. Down moves from the query to the results; Escape closes the picker.
  6. The document owner opens the selected file. If it is already open, Studio activates that draft and preserves its unsaved text. Quick Open itself does not save, replace or reload a draft.

Jump directly to a line

  1. Open Quick Open with Ctrl+P.
  2. Enter main.c:42 to select line 42, or main.c:42:5 for column 5. Choose the intended file from the matching results.
  3. Select Open selected. Studio reveals its editor and moves to the requested position. An already-open file keeps its unsaved text; the position is resolved in that draft.
  4. Use the editor’s Back navigation to return to your previous source location. This changes your location, not your text undo history.

Lines and columns start at 1. Columns count UTF-8 bytes rather than screen cells: a position inside a multibyte character selects its first byte. A column past the line end selects the end. If the requested line is missing, Quick Open stays open and reports the failure; edit the query and select again. A new tab may remain available for inspection, while the previous active document is restored.

For filenames containing colons, quote the filter: "notes:12" searches for that literal name, while "notes:12":4 requests line 4. A trailing colon is incomplete input; finish the number or remove the colon. The filename portion still uses the same literal matching rules.

If a result cannot be opened

A changed index retires the old selection. Choose Refresh results to read the current index from its first page, then select again. This button does not scan disk; use Explorer Refresh to discover filesystem changes.

After switching workspaces, close and reopen Quick Open. Returning to the same folder also requires a fresh picker because it is a new workspace state. A missing or inaccessible file can still fail when the document owner reads it; your other drafts remain open.

Scope

The picker uses existing index ordering, inclusion rules and path limits. It does not include unsaved documents without filenames, automatically discover new files, or search symbol names. Paths shortened visually are kept in full internally; hover over a result for its complete path. Very large indexes may take time to filter because matching runs over the existing in-memory list on the UI thread.

If the picker closes while opening

Quick Open belongs to the workspace session from which you opened it. If that workspace changes while the native window is being created, Studio cancels the picker. Reopen Quick Open in the intended workspace. Opening it repeatedly while construction or presentation is active does not create nested pickers.

Changing the query while rows are being replaced retires the previous page before another page can become actionable. An interrupted display can be empty or incomplete; choose Refresh results to request a new page if it does not recover automatically. A result that cannot be opened leaves your existing drafts unchanged. Successful selection reveals the source editor even if your layout had hidden it.

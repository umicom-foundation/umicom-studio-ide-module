Fold selected code while keeping the complete source

The toolbar now groups these actions under Code tools or Navigate and view. See finding editor tools for their locations and local filters.

Folding hides part of a source draft so you can concentrate on nearby code. The hidden text stays in the document and is still included when Studio saves, searches, copies source for a language request, or applies an edit.

  1. Open a document in the editor. Select at least two source lines. The first selected line will remain visible as a heading.
  2. Choose Fold selection in the editor toolbar. Scroll the toolbar horizontally if the button is outside the visible area. The following selected lines are hidden and the caret moves to the first selected line.
  3. Continue reading the visible code. You can fold separate selections, up to 64 ranges in one buffer. A read-only document can be folded too.
  4. Choose Show all code to reveal every manual fold in the active editor. This does not change the document, mark it dirty, or add an Undo step.

How the selection is interpreted

The action works with source lines, not lines produced by word wrapping. If the selection ends exactly at the start of a line, that final line stays visible. If it ends partway through a line, the entire final selected line is hidden. The first selected line always stays visible, even if selection starts halfway through it. A selection within a single line is refused.

When code becomes visible again

Editing the draft reveals all manual folds. Searching, selecting or navigating into hidden text also reveals the folds, so the destination remains visible. Selecting across an existing fold reveals it before a new fold is requested. Ordinary view refreshes retain folds while their native buffer is kept. Closing that buffer discards its fold state.

Manual folds are not saved to your project or settings. For structural regions, use Syntax folding to request and select a server-supplied region, then use Fold selection. There is no automatic collapse, gutter toggle or persisted nested-fold catalogue. Use Show all code before comparing unfamiliar source. If folding is refused, select at least two source lines and retry; a host callback that changes the selection or draft also invalidates the request.

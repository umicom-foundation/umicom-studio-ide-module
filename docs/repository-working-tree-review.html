Review a project and its submodules

Source Control includes a read-only repository review. A submodule is a child Git repository: its parent stores a commit identifier, while the child owns its files.

  1. Open the project's Source Control surface.
  2. Expand Repository and submodule review and check the displayed path.
  3. Select Inspect repository. Use the page buttons to read each group of changed paths.
  4. If a child has modified or untracked files, review and commit those inside the child before recording its new revision in the parent.
  5. Inspect again after repository changes. Select Stop to cancel a pending read.

A failed refresh retains the older observation and reports the failure. The review does not stage files, commit changes, fetch or push. It cannot prove that commits have been published or that builds and tests passed.

The panel currently supports Windows and non-Android Linux GTK builds. It displays up to 50 paths per page within Framework's bounded 4,096-entry observation.

Inspect one test run

The Test Explorer can retain evidence from several executions of the same test. Choose a run to keep its report, source locations and exported CSV together.

  1. Open Test Explorer and select a discovered test. Read Running tests if the project has not been configured and discovered.
  2. Open the Selected test tab. The Evidence run control starts with All retained runs.
  3. Choose a named run. Its label includes the number of retained result and output records. The report now displays only that exact test and run. A run with output but no result does not count as a pass.
  4. Open the Source locations tab to inspect links from the same selected run. Read the location and working directory before opening it. Studio retains any unsaved draft already open for that source.
  5. Return to Selected test and choose Copy selected evidence CSV to copy that same scope. Review the CSV before sharing it; process output may contain project paths or other private data.
  6. Choose All retained runs to compare recorded executions again. Selecting another test resets the run choice to all runs for that test.

Reading the evidence

Run IDs are sorted as strings, not as dates. The summary separately counts records without a run ID; these appear only in the all-runs view. The report retains up to 32 matching results and 64 output records, with matching totals showing omissions. The Results, Coverage and Output tabs remain aggregate views and are not filtered by this control.

Missing or changed runs

If records for the selected run are removed, the picker keeps an Unavailable run entry. Select another run or explicitly choose all runs. A missing run never becomes a successful test. If evidence changes while a source row is being prepared, refresh and choose its current location again; an old retained button cannot open a different run's source.

This filter reads retained evidence and launches no test. It does not recover files from an earlier checkout. Relative source references use the current test working directory shown in the source-location pane. A directory, file or line that no longer exists requires review of the original evidence.

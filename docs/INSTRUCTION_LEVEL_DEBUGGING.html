Stepping through C and Assembly in Umicom Studio

Follow a native programme one machine instruction at a time and stop at a selected instruction.

Prepare the Notes project

Open framework/examples/development/c_assembly_notes and build the Debug configuration. Configure GDB DAP or LLDB DAP in Run and Debug, then place a source breakpoint before the call to UmiNotesCountByte().

Start debugging and continue until the programme is paused. Select the intended thread and stack frame before using machine-level controls.

Open Registers and Disassembly

In Run and Debug, open Registers and Disassembly. Refresh low-level inspection so the panes describe the selected stopped frame.

The Registers pane shows processor state supplied by the adapter. The Disassembly pane shows addresses, instruction bytes, mnemonics and operands. The row marked as current follows the program counter when the adapter exposes one.

Step one instruction

The Disassembly pane provides two machine-level controls in addition to the existing source-level debugger controls.

ControlUse
Step InstructionPerform a DAP next request with instruction granularity.
Step Into InstructionPerform a DAP stepIn request with instruction granularity.

After the command is accepted, wait for the next paused state. Refresh low-level inspection again to compare changed registers and the new instruction pointer.

Source Step Over and machine Step Instruction answer different questions. Use source stepping while reasoning about C statements; use instruction stepping when studying generated code, calling conventions or an Assembly routine.

Set an instruction breakpoint

Select an instruction in the Disassembly pane and choose Toggle Instruction Breakpoint. When the active adapter supports instruction breakpoints, Studio asks Framework to synchronise the complete instruction-breakpoint set with the debugger.

Choose the same instruction again to remove the breakpoint. The breakpoint decoration changes only after the adapter accepts the updated set.

Practice the C-to-Assembly transition

  1. Pause immediately before UmiNotesCountByte().
  2. Refresh Registers and Disassembly.
  3. Use source Step Into to enter the function, or use Step Into Instruction to move at machine level.
  4. Observe the instruction pointer and the registers carrying the function arguments.
  5. Select a later instruction in count_byte.S and toggle an instruction breakpoint.
  6. Continue and confirm that the debugger pauses at the selected instruction.
  7. Refresh again and compare the registers with the previous stop.

If an adapter does not advertise disassembly or instruction-breakpoint support, continue using the capabilities it does provide. Studio presents Framework's debugger state; it does not emulate unsupported debugger operations.

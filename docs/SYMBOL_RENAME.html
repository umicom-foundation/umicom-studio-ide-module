Rename a symbol in Studio

This guide describes the single-draft mode. For the explicit additional-drafts workflow, see Rename across open drafts.

Use a language server to propose a name change for a function or variable in the current writable draft. Studio reviews the complete returned change before applying it. It never turns this operation into a global text replacement.

  1. Open the source document and place the caret on the symbol.
  2. Choose Rename… in the editor toolbar.
  3. Enter the installed language server's absolute executable path, arguments and absolute project folder. Load saved server can fill the executable and arguments from local preferences. Opening the form and loading preferences do not launch a process.
  4. Enter the new name and choose Request rename. The local server receives this captured draft and may read the project folder.
  5. Read the returned document list. Studio can apply this proposal only if all changes belong to the one captured document. A proposal containing other documents stays entirely unapplied.
  6. Choose Preview complete draft. Review the original and proposed text, changed ranges and numbered explanations. Read each explanation marked Confirmation required.
  7. Approve the displayed rename and confirmation requests, then choose Apply to captured draft. Use Undo to restore the captured text, or Save separately when you want to write the result to disk.

If you change the new name or server settings, request and review again. If the draft, caret, selection or permissions changed, close and reopen the form. Cancel leaves the draft untouched. Server descriptions are displayed as ordinary text; they cannot execute markup or issue commands.

Some symbols have uses in several documents. Studio's current rename review refuses those proposals as a whole; it does not apply just the current document. File creation, file renaming and file deletion are also unsupported by this action. Only the captured draft is synchronized with the temporary server, so other unsaved documents are not treated as current server knowledge.

If no rename is available, check the symbol position, new name and server setup. The new name must fit within 1024 UTF-8 bytes and contain no control characters; the server checks the language's naming rules. Large source messages and slow server startup can exceed the temporary connection's size and time limits. Saved server settings are ordinary local preferences and should not contain credentials.

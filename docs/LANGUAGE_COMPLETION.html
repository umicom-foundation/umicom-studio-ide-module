Review language completions in Studio

Studio's editor command bar includes Complete…. It requests suggestions from a local language server that you choose. Framework captures the draft, handles the temporary connection and applies an accepted result through the same Undo history as other edits.

  1. Open a writable source file. Select a typed word within one line if you want it replaced. Otherwise leave the caret where text should be inserted.
  2. Select Complete…. If the command bar is narrow, scroll it horizontally. Opening the form sends nothing.
  3. Enter the absolute language-server executable path, its arguments and the project folder. Select a program you trust to read source and inspect that folder.
  4. Select Request suggestions. Wait for the temporary connection to close and the suggestion list to appear.
  5. Choose a suggestion and select Preview complete draft. Review the entire result, including additional imports. Select the approval checkbox and Apply to captured draft only when it is correct.
  6. Use Undo to restore the earlier draft, or Save to write the accepted result to disk. Cancel leaves the draft unchanged.

If the source or selection changed, close the review and start again. Editing connection fields or selecting another suggestion invalidates approval. Server snippets and commands are refused rather than applied as ordinary text.

This explicit action does not yet supply automatic completion popups or a persistent server session. It does not install servers. The native message limit is 65536 bytes per JSON message, including the protocol envelope and escaped source, with 4096 parser tokens; escaping may make a smaller source exceed that limit. Drafts of 65536 bytes or more are refused before launch. Each replacement span is limited to 511 UTF-8 bytes and 64 additional edits. The request uses a five-second read budget. A large project or a server requiring client-side configuration requests may need a future persistent-session integration.

Save and reuse your choice

  1. After entering the server path and arguments, choose Save server for this language. Studio reports the file in your user-local settings.
  2. When you reopen the form, choose Load saved server. Review the loaded values and current project folder.
  3. Choose Request suggestions when ready. Load does not start the server, send source, or change the editor.

Use these settings for ordinary flags, never API keys or passwords; the local JSON file is not encrypted. A missing, invalid or wrong-language file is rejected. Editing the fields during a load discards the pending result. A save uses the values present when you selected Save and may finish after closing the form; save again if you want to keep newer edits. Each language has its own file. The workspace folder is not saved as part of the server choice.

The Outline panel's connection check is separate: it checks initialization and shutdown without sending the draft.

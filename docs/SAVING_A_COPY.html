Save a separate copy in Studio

Use Save Copy when you want a separate file containing the current draft while continuing to edit the original source.

  1. Focus the source tab you want to copy.
  2. Choose File → Save Copy…, or search for Save Copy in the command palette.
  3. Select a new filename in an existing local folder. The suggested name starts with copy-.
  4. Read the result notification. The source keeps its filename, Undo history and unsaved marker.

The command captures your draft when you invoke it. Typing or switching tabs while the chooser is open does not change the captured copy. Cancel the chooser and invoke Save Copy again to include newer edits.

Supported output

The copy keeps the selected UTF-8, UTF-8 BOM or UTF-16 format and exact visible line endings. It can copy a read-only source. The output must be a new file: even if a native dialog offers replacement, Studio refuses to overwrite an existing destination. Use another name.

A local absolute path is required. Network UNC paths, device paths and paths containing dot segments are not supported by this writer. Existing directories are required. If a storage error leaves a partial new file, Studio reports that possibility and retains the file for inspection.

Command clients

Native clients can execute file.save-copy with an absolute destination argument. A missing argument opens the chooser. An accepted chooser request is not evidence of a completed write; the completion notification reports the result. Closing Studio before completion cancels the pending write.

Save As remains the action for giving the working document a new saved identity. Save Copy creates an independent file and does not open another editor tab.

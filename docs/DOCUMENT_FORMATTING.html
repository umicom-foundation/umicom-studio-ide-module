Format a document in Studio

To focus a request on selected text, use selected-range formatting and review its complete result. Whole-document formatting remains the default.

The editor's Format… action asks a selected language server to format your complete draft, including unsaved text. Opening the form does not start the server or change the document.

  1. Open a writable source document and choose Format…. Scroll the editor command bar horizontally if the action is outside the visible area.
  2. Enter a trusted server's absolute executable path and arguments, or choose Load saved server. Check the project folder. You can save the path and ordinary arguments for this language; they remain local JSON settings.
  3. Choose tab width and whether to use spaces. These options apply to this request. Formatting covers the whole document even if text is selected.
  4. Choose Request formatting, then Preview complete draft. Inspect the complete result before selecting the approval checkbox.
  5. Choose Apply to captured draft. Undo restores the earlier text; Save writes the accepted text to disk. Cancel changes nothing.

If the draft or selection changed, close the form and capture again. Changing server or indentation settings discards the previous result. An empty result is valid and leaves the document unchanged. Completion and formatting share one review slot.

The server must support document formatting, open/close synchronization and UTF-16 positions. This temporary workflow has a five-second read budget and a 65536-byte JSON message capacity including escaped source and the envelope, with at most 4096 parser tokens. It rejects invalid or overlapping edits and does not implement format-on-save, range formatting, persistent indexing, server installation or client configuration callbacks.

Keep credentials out of server arguments; saved settings are not encrypted. See saved server choices and completion for the related editor workflow.

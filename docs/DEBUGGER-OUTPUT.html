Review debugger output in Studio

The Debugger output section shows retained output from Studio's debugger service. Refresh captures results once so you can read pages without incoming output moving them.

  1. Open a project you trust and open the debugger surface. Expand Debugger output.
  2. Choose optional session, category, text, severity and ordering filters. Empty session and category fields include every retained session or category.
  3. Select Refresh output. The first page contains at most 64 records. Use Next and Previous to read the same capture.
  4. Change filters and refresh to take a new capture. Use Copy page to copy only the current page, or Clear view to clear the display without clearing the debugger's records.

This section is an output viewer. It does not run commands or evaluate expressions. It can review retained output after debugging stops. A project must remain trusted when a new capture is requested.

If nothing appears

Check project trust, remove restrictive filters and refresh. If the debugger has not supplied output, the result is empty. A failed refresh clears the old view rather than presenting it as a new result. Reopen the project if its workbench was closed. Review copied output for private paths or data before sharing it.

The viewer retains at most the service's current bounded registry and is not a complete saved transcript. Text matching is bytewise case-insensitive and exact session/category matching is case-sensitive.

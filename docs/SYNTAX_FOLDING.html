Find and fold a structural code region

A language server can identify blocks, comments and other regions in the current draft. Studio lets you inspect those regions, select one, and collapse it with the existing folding control. The source stays complete: folding changes its display, not its saved content.

  1. Open the source document. In Code tools, choose Syntax folding…. The form captures the current draft. Opening the form does not start a server or hide text.
  2. Choose a trusted language-server executable using its full path. Review its arguments and working folder. A local language server is a program with access to your project; use the server intended for this language. The existing local server preferences can supply these fields.
  3. Choose Find folding regions. Studio starts a temporary connection, sends the captured draft, waits for the folding response and closes the connection. The server must advertise folding support. Errors leave the current draft unchanged.
  4. Choose a region from the list. The displayed end position is excluded: an end at line 8, column 1 selects through line 7. Changing the list choice does not move the editor. Choose Select region to select those lines. If the draft or captured selection changed, close the form and capture again.
  5. In Navigate and view, choose Fold selection. The first selected line remains visible and the remaining lines collapse. A single-line region has no body to collapse and is refused.
  6. Choose Show all code to reveal the text. Editing the draft or navigating into hidden text also reveals folds. Read-only documents support the same presentation controls.

What to expect

Discovery preserves the server's region order, including nested, overlapping or duplicate ranges. It does not collapse every result automatically. The current query sends one draft and uses the existing bounded native transport: the draft must be smaller than 65,536 bytes, and the escaped request and response must fit the transport and parser limits. The owned catalogue accepts up to 4,096 complete regions; a malformed or oversized result is rejected rather than partly displayed.

Folding operates on complete source lines. Character-level folding, custom collapsed labels, a gutter toggle, fold-all, persistent fold settings and continuous server refresh are not provided by this workflow. A blank final line contains no source bytes to hide. See manual folding for the 64-range presentation limit and reveal behavior.

If a request does not succeed

Check the executable path and arguments first. A server without folding or document-open support cannot provide this query. If no regions are returned, select suitable lines manually and use Fold selection. If the source changed while a request was running, start a new request from a new form. The result depends on the language server and project configuration; Studio does not guess structural regions when a server fails.

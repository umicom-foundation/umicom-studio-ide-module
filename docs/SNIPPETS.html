Compose and review a snippet insertion

The toolbar now groups these actions under Code tools or Navigate and view. See finding editor tools for their locations and local filters.

A snippet is a short template with values you can fill in before inserting it into your source. Numbered values can appear more than once. Changing one value updates every linked occurrence in the expanded template.

  1. Open a writable source draft. Place the caret where the template should go, or select the text it should replace.
  2. Choose Snippet… in the editor toolbar. The form captures the current draft and selection. It works locally and does not start a language server.
  3. Enter a template. For example, ${1:name} = $1;$0 expands to name = name;. The first numbered value supplies a default, the repeated number links to it, and $0 marks the final caret.
  4. Choose Expand template. Select a numbered value from the list. Edit its text, then choose Update linked value. The expanded text shows every affected occurrence. Values are literal text, so dollar signs entered as values are not interpreted as new placeholders.
  5. Choose Preview complete insertion. Compare the entire captured source with the proposed draft, including the surrounding text. A selection is replaced; an empty selection inserts at the caret.
  6. Select I approve the displayed insertion, then choose Apply to captured draft. The form closes after a successful insertion. Save the source when you are ready.
  7. Use Undo to restore the complete draft from before insertion. Earlier unsynchronized typing remains a separate Undo step.

Template forms

Use $1 or ${1} for a numbered placeholder, ${1:default} for a literal default, and ${2|one,two|} for choices. The first choice is the initial value. Choices are suggestions: you may enter another value. Use a default at the first occurrence and bare references afterward. Use $0 once for the final caret; without it, the caret follows the expansion.

This form uses the existing bounded local snippet grammar. Nested placeholders, variables, transforms and escape sequences are not supported. Unsupported forms may remain literal text; always check the expansion. Named templates can now be saved and loaded locally by name. There is no searchable template catalogue, inline Tab traversal after insertion, or complete language-server snippet compatibility.

Save a template for later

  1. Enter a short, memorable Template name, such as loop or error check. Names are case-sensitive and separate for each document language.
  2. Choose Save named template. This saves the template text, including placeholder syntax, rather than the expanded values. Saving the same name for the same language replaces that saved template.
  3. In a later review, enter the same name and choose Load named template. Loading changes this form only. Choose Expand template and follow the normal preview and approval steps before insertion.
  4. Read the result message for the local file path. On Windows, the default location is under your local application data folder in Umicom/Studio/config/snippets. Language and template identities use encoded directory names so slashes and case cannot redirect storage.

These files are ordinary local JSON text. They are not an encrypted credential store; do not put API keys or passwords in templates. They are not sent to a server or placed in your source repository by this feature. File access runs on a worker. A load result is discarded if you edit the form or close it while loading. A Save already started may finish after closure; its result records the captured template, not newer edits. Concurrent saves to the same name use last-writer behaviour.

If loading fails, check the exact name and document language. A malformed file or mismatched stored identity is refused without changing the source draft. Path lengths and file permissions remain subject to your operating system. There is no automatic directory scan or template deletion action.

If Apply is unavailable

  1. After changing template text, choose Expand template again. Expansion resets entered values to the template defaults.
  2. After editing a value, choose Update linked value. Then prepare a new preview and approve it. Changing a field expires the earlier approval.
  3. If the source, caret, selection, permissions or save/conflict state changed, cancel and open a new snippet review.
  4. Keep the template below 8,192 UTF-8 bytes, each edited value below 512 bytes and the expanded template below 16,384 bytes. A non-ASCII character may occupy several bytes. The complete draft must also fit the editor's eight-MiB text limit.

For assistance from a local language server, see source navigation. Snippet values stay editable in this review form; insertion itself creates ordinary source text.

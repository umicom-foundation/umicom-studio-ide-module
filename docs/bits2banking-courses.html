Follow Bits2Banking courses in Studio

Bits2Banking contains learning material. Studio uses the Framework learning catalogue to read a selected pack without copying the lessons into your source project or running their examples.

Open the connected courses

  1. On Studio’s welcome page, select Follow Bits2Banking courses. The same action is available in Guided Learning. It opens the shared catalogue and requests the collection overview.
  2. If the collection has not been loaded, the catalogue reports that the matching local pack is missing. Choose the folder containing its learning-pack.json: normally C:\umicom\Umicom-Bits2Banking\content\courses\framework-and-finance. Use your own checkout location when different.
  3. Select Load learning pack. Wait for loading to finish, then select Follow Bits2Banking courses again, or select the overview in the results and choose Open selected.
  4. Choose a module and its first lesson. Use its Previous, Next and Course overview links. Back and Forward preserve the current reading sequence.
  5. Read the worked example, try its exercise and compare your explanation with the worked answer. Source-reading sections identify actual Framework files.

This collection has twelve introductory modules and twenty-four lessons. It connects software architecture, Studio documents, data, security, banking, payments, treasury, accounting, trading, delivery, AI and integration. It does not include every longer course in the browser library.

Record progress deliberately

  1. Expand Private learning checkpoints.
  2. Enter an absolute database filename in a folder you choose. Keep it separate from shared course content.
  3. Enter a Local learner ID, a Checkpoint ID and an Evidence reference. For example, use learner-1, reviewed and exercise-1. These short identifiers are not a place for personal notes or file paths.
  4. Use Inspect checkpoint to read an existing record, or Record checkpoint to append an activity you completed. Inspect does not create a missing database. The parent folder must exist. These controls require a build with learning progress storage enabled.

Progress is local and optional. Opening a page does not automatically mark it completed. No trading or banking credentials are needed.

Keep practice work separate

Create a practice project in a folder you choose. A lesson’s source reference is for reading; do not edit your main Framework checkout to complete a paper exercise. Review project trust and build settings before running any example. Reading a pack grants no execution permission.

Use the full browser library

Open content/courses/index.html inside your Bits2Banking checkout in a browser. It links the existing programming, Framework, OS, Kernel and LLM courses. The native reader admits only resources declared inside its selected pack; it does not open arbitrary outside paths.

Troubleshooting

  • Matching pack missing: load the collection folder, then repeat the course action.
  • Changed file or checksum error: use a consistent published collection. A maintainer must review changes and regenerate the manifest; do not disable verification.
  • Version refused: the collection declares Framework 0.9.0 compatibility. A different host needs a reviewed range update.
  • Parent-folder link refused: the old reader accepted sibling links only. Use the updated Framework navigation or continue reading in a browser.
  • Studio action does not respond: record the action and observed result. The browser route remains available while that runtime issue is investigated.

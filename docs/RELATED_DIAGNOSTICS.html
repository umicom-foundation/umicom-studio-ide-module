Open related source from Problems

A diagnostic can explain where a problem was found and point to another location that helps explain it. For example, a duplicate declaration may identify both declarations. Problems presents these destinations alongside the complete diagnostic text.

  1. Open a source document and choose Problems….
  2. Select your local language server and project folder. Choose notification diagnostics, or enable explicit pull diagnostics if the provider requires them.
  3. Choose Capture source diagnostics, then select a diagnostic in the message list.
  4. Read the complete message and its related information. In Source location to open, select the primary reported range or a numbered related destination. The primary range is selected initially.
  5. Review the destination URI and position. Choosing a row does not open a file.
  6. Choose Open reported range. Studio opens the selected source destination and selects its exact range. If the document is already open, its unsaved text is preserved.

Understanding the result

The original captured draft must still match the diagnostic request. Studio also checks the selected destination against its current text before moving the caret. Read-only documents permit navigation, and successful opening records a normal source-navigation jump. No text is edited, saved or added to Undo.

External related text was not captured by this one-document query. Checking its range shows that the position exists in the current draft; it does not prove that the server's analysis of that other file is still current. If an external file has changed, request diagnostics again and inspect the current source.

Recover from an unavailable destination

  1. If you changed the captured source or caret, close Problems and capture again. Changing text back does not restore the previous document revision.
  2. If a target range no longer fits the current document, Studio leaves the active source unchanged. Capture a new report instead of assuming an adjusted line or column.
  3. Remote web addresses, remote file authorities, URI queries and fragments are not opened by source navigation. Explanation addresses remain literal text.
  4. Choosing another diagnostic resets its destination to the primary reported range. Each diagnostic has its own related-information list.
  5. Changing server settings or closing the review retires its destination choices. A retained control cannot navigate from an expired publication.

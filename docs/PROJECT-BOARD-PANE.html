Use a project board inside Studio

The Project Board pane lets you plan work while keeping your editor open. It uses the same Framework board editor as the separate Kanban window.

  1. Open your project in Studio.
  2. Choose Project Board in the activity rail, or run view.kanban from the command palette. Opening the pane alone does not access a board file.
  3. Click Dock current project's board. Studio reuses an existing window for that project when available.
  4. Choose an existing private folder. Review the suggested filename, then choose Create board or Open board. Do not place private planning files in a public source repository.
  5. Add cards, type developer names to assign work, and drag cards between the board's columns. Use Save board to retain these changes.
  6. Click Open board in separate window when you want more space. The same board and unsaved edits move with it.

Changing projects

The pane shows the board's captured project path. Opening a different Studio project does not silently change that board. Click Dock current project's board to choose the new project's board. The previous board returns to its separate window, preserving unsaved edits.

Closing Studio

Closing Studio returns a docked board to its separate window. Save or explicitly close that window when finished. Closing a layout pane only hides its retained contents. Terminating the whole process cannot preserve unsaved memory.

When docking is refused

Wait for the current board file operation to finish. If the board is already docked in another Studio window, return it there first. A build without native Kanban support displays an unavailable message. Existing independent board windows remain available through the project explorer's board command.

Website generation and saved publication selections remain separate, explicit actions. Docking never uploads a board.

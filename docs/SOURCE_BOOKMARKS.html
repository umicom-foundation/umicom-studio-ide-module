Return to important lines with bookmarks

A source bookmark remembers a line in an open document. It helps you move between code you are investigating without changing the text or saving the document. Bookmarks also work in untitled drafts and read-only documents.

Mark and revisit a line

  1. Open a source document in the Editor workspace and place the caret on a line you want to revisit.
  2. Select Bookmark Line in the editor command bar. This remembers the line and the current column.
  3. Move to another line or open another document. Mark more locations if needed.
  4. Select Next Bookmark or Previous Bookmark. The editor visits bookmarks in the order you added them, wrapping at the end. If the current line is not bookmarked, Next starts at the first bookmark and Previous starts at the last.
  5. Use Navigate Back to return from a bookmark jump through the normal navigation history.

The same commands are available in command search under Navigate. Their command identities are editor.bookmark.toggle, editor.bookmark.next and editor.bookmark.previous. Availability is checked again when a command runs.

Remove bookmarks

  1. To remove one bookmark, visit its line and select Bookmark Line again. Moving the caret to a different column on that line does not create another bookmark.
  2. To clear the complete set, find Clear Bookmarks in command search. This removes location metadata only; open documents and text Undo history stay intact.

Understand what is remembered

Bookmarks last for the current editing session and are not saved to disk. Up to 64 locations can be marked. A bookmark keeps the identity of its original open document, so Save As can retain it, but closing and reopening a path creates a different document. Old bookmarks never redirect to another tab with the same name.

Positions are fixed line and column coordinates. They do not follow text when lines are inserted or removed. A jump skips a closed document or a line that no longer exists, and clamps a column to the available text. Check a bookmark after substantial edits and toggle it again if you want a different location.

If a command cannot continue

SituationNext step
A save, close, replacement review or clipboard decision is in progress.Finish or cancel that decision, then retry the bookmark command.
No bookmark can be visited.Mark a line in an open document. Closed-document bookmarks remain in the session count until cleared.
The bookmark capacity is full.Toggle unwanted bookmarks off, or use Clear Bookmarks and mark the locations you still need.
A bookmarked line moved after editing.Find the intended text, remove the old fixed-line bookmark if it is still available, and mark the new line.

Bookmark commands do not reopen files, run code or save source changes.

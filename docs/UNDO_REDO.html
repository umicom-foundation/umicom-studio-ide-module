Undo, Redo and your editing position

Studio uses one shared document history for native typing, replacements, line commands and reviewed source changes. History belongs to each open document. Undo does not save or overwrite a file on disk.

Restore an edit

  1. Open a source file and select a few characters.
  2. Type replacement text. The accepted typing group becomes one history step, even when the toolkit deletes the selection before inserting new text.
  3. Choose Undo. The original source and selected range return.
  4. Choose Redo. The replacement text and the position you left before Undo return.

The selected range is restored. Selection direction is not recorded separately: a backward drag can return as the same range with the opposite active end.

Commands and reviewed changes

Indent, duplicate, replacement, completion and other document commands retain the departure selection with their source. A saved-file reload does too when it changes text. Reviewed changes spanning several files still have separate per-document Undo; undoing one file does not undo every member of a source edit set.

If you move the caret before Undo, Redo returns to that departure position. If you move it before Redo, a later Undo returns to the new position. A command that changes no text adds no history entry.

Limits and recovery

Each document keeps at most 32 entries in each direction, subject to a 16 MiB text budget per stack. Older entries are evicted together with their positions. Closing a document releases its in-memory history; this is not a persistent recovery journal.

Earlier text-only synchronization may have no captured departure position. Those entries restore text and clamp the current selection to valid character and line-ending boundaries. Accepted native typing uses a capture. If the document changes ownership or its store changes during a typing group, the group cannot be recorded; Studio keeps the visible draft and reports the history failure. Preserve that draft before closing it.

Read-only documents refuse history traversal. See line editing for commands that use the same history.

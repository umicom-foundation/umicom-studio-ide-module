Review replacements in open Studio documents

Use this workflow when the same literal text needs changing in several open source files. Studio shows a before-and-after comparison for each changed draft so you can decide separately.

  1. Open the documents you want to review. Include unsaved or pinned tabs if they need the same edit.
  2. On the editor toolbar, enter the existing text in Find and the new text in Replace with. Leave Replace with empty to remove matching text.
  3. Choose Review Open Documents. On a narrow window, scroll the editor toolbar horizontally to reach it. You can also search for Review Replacements in Open Documents in command search; it uses those same fields.
  4. Read Captured draft and Proposed draft. Both comparison panes are read-only. Choose Apply to this document to change this draft, or Skip this document to leave it alone.
  5. Repeat for each question. Choose Stop when you want to leave the remaining drafts untouched.
  6. Read the result counts, then choose Close. Check the changed tabs and use Save when ready to write them to disk.

Try a small example

Open two drafts containing customer_name. Find customer_name and replace it with client_name. Apply the first question and skip the second. The first draft should contain the new name; the second should remain unchanged. Return to the first tab and use Undo to restore its previous draft. Saving remains a separate action.

Search rules and limits

Matching is literal, with no regular expressions or replacement templates. ASCII uppercase in Find requests case-sensitive matching; otherwise ASCII letters match without case. Non-ASCII text matches exactly. The starting set includes untitled and pinned drafts. Later-opened tabs and unopened project files are excluded. No-match, unchanged, read-only and already-closed documents are counted without an Apply question.

The existing Replace All button continues to review replacements in the active document only. The open-document workflow applies one reviewed draft at a time and retains the active tab.

If the review stops

A draft that changes after its question is captured cannot accept that old proposal. Close the result, inspect the newer text and start again. Changing the Find or Replace with fields does not change a question already underway.

Stop and errors keep earlier accepted edits. There is no global rollback: Undo belongs to each changed document. Closing the Studio host cancels pending review work. A button retained from a closed review cannot edit a later document.

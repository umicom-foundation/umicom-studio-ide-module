Comment source lines in Studio

  1. Open a source file, for example a C file, Python file or CMakeLists.txt.
  2. Place the caret on a line, or select a group of lines.
  3. Choose Toggle language comment in the editor actions.
  4. Review the result and save when ready. Use Undo to reverse the edit.

The command uses the document language: // for C, # for Python and CMake, and -- for SQL. Other known line-comment languages are listed by Framework's comment-style catalogue. If all selected nonblank lines already carry the prefix, the command removes it; otherwise it adds the prefix.

It is unavailable when the source is read-only, no supported language is known, or another editing review prevents changes. The original explicit // comment action and its shortcut retain their behaviour.

This is a line-editing tool, not a parser. Review string literals, shebang lines, multiline strings and embedded languages yourself. JSON, HTML, CSS, Markdown, generic Assembly and plain text have no automatically guessed comment prefix. The action does not save or execute source code.

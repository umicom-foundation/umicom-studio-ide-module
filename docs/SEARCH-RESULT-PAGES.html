Search result pages

  1. Open a project and open the Search panel.
  2. Enter literal text in Text to find. Optionally choose Match case and relative include/exclude patterns such as *.c;*.h.
  3. Select Find in Files. Search reads saved files in the background; it does not save editor drafts.
  4. After completion, use First, Previous, Next and Last to browse up to 64 results at a time. The range states which results are visible.
  5. Select a result to open its captured location. If the match moved, keep your draft and search again.

The displayed scope belongs to the completed request. Editing the query or patterns prepares the next request; it does not relabel old results. A new accepted search starts at the first page. An unchanged periodic refresh keeps the same result buttons.

When results disappear

Changing or reopening a workspace, or refreshing its file index, invalidates previous results. Search again. A retained button from an earlier page cannot open a result from a newer request.

Limits

The existing search limit is 1000 matches. Narrow the query or file patterns when that limit is reached. Paging changes the number of visible widgets; it does not change search coverage. Cancellation applies only to search, not to a separate build or test process.

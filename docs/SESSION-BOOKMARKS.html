Return to a source location

  1. Open a file or an untitled document and place the cursor on a useful line.
  2. Select Toggle Bookmark in the editor controls.
  3. Open Bookmarks from the View/window catalogue.
  4. Use Refresh bookmarks if the list was already open.
  5. Select a location. Studio reveals the editor and navigates within the current draft.
  6. Use Remove marker to forget a location while keeping the file and its text.

A closed-document marker remains visible with a disabled visit button. It can still be removed. Reopening a filename does not give a new tab the old tab's identity.

Markers last for this editing session only. They use fixed line and UTF-8 byte columns; they do not track inserted or deleted lines. A missing line refuses navigation. Use Navigate Back to return from a successful visit. No action here saves source files or discards unsaved text.

If a command is refused, finish pending save or close decisions and refresh. Other applications can embed the same Framework bookmark panel without duplicating Studio's implementation.

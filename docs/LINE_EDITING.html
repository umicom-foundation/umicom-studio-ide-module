Editing complete lines

Line commands help you rearrange source without selecting and retyping each line. Studio uses Framework's document coordinator, so changes belong to the same draft and Undo history as other editor operations. They do not save the file.

Duplicate and move code

  1. Open a writable UTF-8 source file in the Editor and place the caret on a line.
  2. Open Code tools and enter line editing in its search box.
  3. Choose Duplicate current line. A copy appears below the original and the caret moves to the copy.
  4. Choose Move current line up or Move current line down to exchange that line with its neighbor. These commands operate on the caret line even when text is selected.
  5. Use Undo to restore the text. Save only when you want to write the draft to disk.

Indent and comment a selection

  1. Select text across the lines you want to change. A selection ending exactly at the next line's start excludes that next line.
  2. Choose Indent selected lines to add four spaces, or Outdent selected lines to remove one tab or up to four spaces.
  3. Choose Toggle // comment to add the literal // prefix after indentation. If every nonblank selected line already starts with //, the command removes that prefix and one following space. Blank lines remain unchanged.
  4. The changed complete lines stay selected, so you can repeat indentation or toggle comments again.

The comment command does not detect the language. Use it only where // is appropriate. Framework callers can supply another literal prefix.

Join, remove and trim

Join next line combines the caret line with the next line, removes the next line's leading spaces or tabs and inserts a space when both lines contain text. Delete current line removes the caret line. Trim trailing whitespace removes spaces and tabs at every line end in the complete draft and places the caret at its start.

Expected results and recovery

LF and Windows CRLF line endings are supported. Moving the first line up or the last line down, or joining the last line, reports that no neighbor is available. A read-only draft refuses edits. Finish an open document operation before trying another command.

A changed line command adds one Undo step; earlier unsynchronized typing remains a separate step. Undo restores the text and selection captured before a line command. Redo returns to the text and position you left before Undo. Earlier text-only synchronization steps without a captured position use boundary-safe clamping. An operation that changes no text adds no step.

Source and results are limited to 8 MiB. Invalid UTF-8 and bare CR line endings are refused before publication. Near the size limit, the conservative growth check may refuse a comment toggle even if removing prefixes would shrink the draft. The shared editor tools guide explains discovery and filtering.

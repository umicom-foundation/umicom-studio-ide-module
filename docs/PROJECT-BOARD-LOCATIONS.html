Studio project board locations

Studio can remember a private board folder and filename for each project. The location record belongs to Studio's application configuration folder; it is not written into your source repository. The board window displays the settings folder used.

  1. Open your project and run project.board from command search.
  2. With the board closed, choose an existing private board folder and a .umikb filename.
  3. Click Remember entered location and wait for confirmation.
  4. Create or open the board explicitly. Saving the location does not save its cards.
  5. When you return later, click Recall saved location, check the fields and choose Open board.

Opening the project board again returns to that project's existing window. Switching project does not retarget an already open board. If remembered settings are unavailable, you can still choose a folder and use Open/Create manually.

Close the board before changing its location. A failed recall leaves your later field edits intact. A saved location is not proof that the archive still exists or that you have access: the normal board Open operation performs those checks.

This is a native project window. A docked board pane and shared account-based collaboration are separate capabilities. Location records contain private paths; keep application configuration files out of public commits.

Saved test reports in Studio

Use the Test Explorer’s Open a saved CTest report section to review a previous test run. This review is separate from Studio’s live test execution and archive controls. You can open a saved report without opening a project.

  1. Finish the build, then create XML and a console log with CTest from your build directory: 
    ctest --output-on-failure --no-tests=error --output-junit "C:/work/private/tests.xml" --output-log "C:/work/private/tests.log"
    Use an existing private folder and keep both files.
  2. Expand the saved-report section in Test Explorer. Choose the XML filename and click Open report. The panel reads it in the background.
  3. Review the captured filename, full report counts, and the default non-passed results. Not run, disabled, skipped and timed out remain separate from failed and passed.
  4. Enter part of a test name, choose an outcome or sort order, and click Apply filters. Name matching ignores ASCII letter case. Next and Previous retain that selection until you apply another.
  5. Use Copy page to copy the current 64-record page. Use Close report to discard the loaded view without deleting its file.

Cancel load prevents a pending read from displaying results. It waits for the local read to finish releasing resources. Closing or hiding the panel also prevents late publication. A later load is a new operation.

A saved report is historical evidence. Studio does not claim it matches the current project, source revision or executables. The original console log is still needed for complete failure details. This panel neither reruns failed tests nor changes the live test selection.

If the report cannot be opened, check the absolute filename, complete JUnit XML format, encoding and 64 MiB size limit. A console transcript is not JUnit XML. If a filter is rejected, the status explains that it was not applied and the previously accepted page stays visible. Correct the draft and Apply again. Missing or malformed replacement files and cancelled loads also retain the accepted report and its captured filename. Path and filter choices are captured together when Open report is selected; later edits require another explicit action.

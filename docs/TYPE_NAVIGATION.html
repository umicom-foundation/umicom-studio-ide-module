Find type definitions and implementations

A definition explains where a symbol is declared or defined. A type-definition lookup asks where that symbol's type is defined. An implementation lookup asks for the concrete code behind an interface or other symbol. The language server determines the meaning and supported results for your programming language.

  1. Open a source document and put the caret on the symbol you want to explore.
  2. Choose Type definitions… or Implementations… in the editor command bar. The bar can scroll horizontally when the window is narrow.
  3. Enter or load the local language server's absolute executable path and arguments. Select the absolute project folder. Opening the form or loading settings does not launch the server.
  4. Choose Find type definitions or Find implementations. Studio sends the captured draft to the local process. The server can also inspect project files.
  5. Select a returned location and inspect its destination. Choose Open selected location to navigate. Source ranges are checked against the destination text before opening; no edit or save is performed.

If the request cannot provide a location

  1. If the operation is unsupported, check the language server's capabilities. Supporting Definitions does not imply support for type definitions or implementations; Studio does not substitute one for another.
  2. If the list is empty, confirm the caret and project folder. An empty list means this request returned no location, not that the project passed compilation.
  3. If you edit source, change the caret or change server settings, request locations again. Stale results cannot move the caret.
  4. If an external file is unavailable, check that it exists locally and can be opened. Web destinations are not launched by this workflow.
  5. If the request times out, inspect the server configuration and compilation database. The temporary query has a five-second read budget and does not maintain a background index.

Read-only primary drafts are supported. Only the captured document is synchronized; other unsaved drafts are not sent. Large source messages or results can exceed the native transport limit. Malformed coordinates, invalid Unicode boundaries or failed connection cleanup prevent the result from being used.

For a name-based search across project files, see project symbol search.

Find a named symbol in your project

A symbol is a named part of a program, such as a function, type or variable. Studio can ask your local language server to find symbols across its project index, then open a selected source location. Results depend on the server and its current index.

  1. Open a source document and choose Symbols…. You can also use the symbol action in Outline. The existing document outline remains the default.
  2. Enter or load the absolute path to your language server, its arguments and the project's absolute folder. Choose a server you trust: the process receives the captured draft and can read project files.
  3. Check Search project symbols. Enter a function, type or other name in Project symbol query. An empty query asks for all symbols the server chooses to return. Editing these controls does not launch the server.
  4. Choose Find project symbols. Studio opens a temporary language-server connection, synchronizes the captured document, requests workspace symbols and closes the connection before displaying usable results.
  5. Select a result. Its container name is a descriptive label rather than an inferred parent-child relationship.
  6. Choose Open selected location. Framework checks the destination and exact Unicode coordinates before navigation. The action does not edit or save the source.

Understand which source was searched

Only the active captured draft is synchronized. Other unsaved documents are not sent by this operation. The server decides how to search other project files, so save relevant drafts before requesting a search when their current text matters. Read-only primary drafts can be searched.

A search result is not proof that indexing or compilation has finished. There is no persistent background index owned by this form. Changing source text, selection, server settings, scope or query retires an earlier result; changing a value back does not restore it. Request a new search when needed.

If no usable results appear

  1. If project symbols are unsupported, check whether the server supports workspace symbol requests. Document symbols are a different capability. Uncheck project search to request the current document outline.
  2. If the result is empty, try a less specific query and check the selected project folder and the server's compilation database. Matching rules are chosen by the server.
  3. If the server supplies incomplete locations or a document hierarchy as a workspace result, the complete result is refused. Studio does not guess a destination or silently drop malformed rows.
  4. If a location no longer matches an open document, search again. External destinations must be locally accessible and pass the shared source-opening checks.
  5. If the request times out, inspect the server's configuration. The form has a five-second read budget; a temporary connection may be unsuitable for a large project that needs lengthy indexing.
  6. Keep search text within 4096 UTF-8 bytes. JSON escaping and the 65536-byte native message limit also bound requests and results. Oversized data is rejected, not truncated into a partial list.

For an outline restricted to the captured document, see document symbols.

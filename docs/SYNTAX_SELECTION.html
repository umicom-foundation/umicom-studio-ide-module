Select an expression or enclosing block

A language server understands the structure of the programming language in your source file. Syntax selection asks it for a small range around the caret followed by larger enclosing ranges, such as an expression, statement and function. The exact choices depend on the server and language.

  1. Open a source document and place the caret in the expression or block you want to select. Unsaved drafts and read-only documents are supported.
  2. Choose Syntax selection… in the editor controls.
  3. Enter the absolute path of your local language server and its arguments. Review the project folder before starting it: the local server receives the captured source text.
  4. Choose Find selection ranges. Studio captures the current draft and caret, requests the server's enclosing ranges and closes the query session.
  5. Choose a row in the returned list. The smallest reported range comes first; its enclosing ranges follow in server order. Positions are displayed starting at one.
  6. Choose Select range to move the editor selection to that exact range. Changing the row alone leaves the editor unchanged.

What stays in your document

Selecting a range changes the caret and selection only. It does not edit or save your source and adds no text edit to Undo. Existing unsaved text and read-only status remain intact. Normal source navigation records the jump.

If no selection is available

  1. Check that your language server supports selection ranges and UTF-16 source positions. Studio reports unsupported capability instead of guessing syntax boundaries.
  2. If the server returns no ranges, try another position. An empty range at the caret can also be a valid server result.
  3. If the captured source, caret or server settings changed, close the review and request again. Changing settings back does not restore an expired result.
  4. A malformed parent range, range outside the captured source, or position inside a Unicode character rejects the complete chain. Inner rows are not offered from a rejected result.
  5. Start another review for another caret position. This action does not run a persistent language server or automatically expand selections through a keyboard shortcut.

The reader accepts up to 64 enclosing ranges. Native transport and JSON message limits also apply, so unusually deep or large replies may be rejected earlier.

Review formatting for selected source

Use selected-range formatting when you want a language server to focus on a part of the current document. The server may adjust surrounding code to keep indentation or syntax consistent. Studio therefore presents the complete resulting draft before you apply anything.

  1. Select the source text to format before opening Format…. A selection can span several lines.
  2. Enter or load your local language server's absolute executable path and arguments, and select the absolute project folder. The process receives the complete captured draft and can read project files.
  3. Check Request formatting for the captured selection. This option is available only when the captured source has a nonempty selection. Leave it unchecked for whole-document formatting.
  4. Choose the tab width and whether indentation should use spaces, then choose Request formatting. Changing controls alone does not start a process.
  5. Choose Preview complete draft. Inspect every difference, including any adjustments outside your original selection.
  6. Approve the displayed result and choose Apply to captured draft. The change stays in the editor; Save remains a separate action. Undo restores the previous draft.

Recover from an unavailable or stale result

  1. If the server does not support range formatting, explicitly leave the selection option unchecked to request whole-document formatting. Studio does not silently change the request's scope.
  2. If no text was selected, close the form, select text and open it again. The form uses captured source rather than following later editor selections.
  3. If source, selection, server settings or formatting options change, request and review again. Changing an option back does not revive an earlier result.
  4. If the server returns overlapping or invalid edits, no partial draft is applied. Inspect the server configuration and retry from current source.
  5. If the request exceeds its timeout or message limit, inspect the selected server and project settings. The temporary connection shares a five-second read budget and has a 65536-byte serialized-message limit.

Formatting uses exact Unicode positions. It does not round a range that splits a character, auto-save the result or keep a persistent language-server connection. An empty edit list simply leaves the captured draft unchanged.

Inspect source in Studio

Use source inspection to understand the complete visible draft, including unsaved edits and selected text.

  1. Open a source document or create a new one. You do not need a project or a saved filename.
  2. Select a range if you want separate selection counts. Otherwise the Selection column describes empty text.
  3. Choose Inspect source on the editor toolbar. On a narrow window, scroll the toolbar to reach the action.
  4. Read the UTF-8 bytes, Unicode scalars, UTF-16 units and line-ending counts. Invisible-character notices show codepoints and locations as plain text.
  5. Close the inspection before opening another one. Reopen it after editing to capture the new draft.

The inspection is independent of later edits or tab changes. It never saves, reloads, changes selection, edits text or adds an Undo entry. Read-only sources are supported. The parent window owns the native inspection window.

Interpret results carefully

One displayed glyph can contain several scalars. The word counter splits only on ASCII whitespace, and an empty document or selection has one logical line. CRLF counts as one line break but two scalars and UTF-16 units. Notice columns count scalars, not tab-expanded screen columns. Invisible characters may be intentional; a notice is a review cue, not a security finding.

If inspection cannot open

Open a text document, finish an active save or close operation, and close any existing inspection. Source must be valid UTF-8 without NUL and no larger than 8 MiB. The first 4,096 notices are displayed, with the full total reported. Failure leaves your draft unchanged.

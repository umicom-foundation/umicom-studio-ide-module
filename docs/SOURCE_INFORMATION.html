Inspect a symbol in Studio

Source info… asks a selected local language server for documentation at your caret. It works with unsaved text and read-only documents and never applies an edit.

  1. Open a source document and place the caret immediately before the symbol. If text is selected, the request uses the selection's start.
  2. Choose Source info… in the editor command bar. Scroll the bar horizontally if necessary. Opening the form captures the draft but does not start the server.
  3. Enter a trusted server's absolute program path, arguments and project folder, or choose Load saved server. Completion and formatting use the same per-language settings. Review loaded values before starting a program.
  4. Choose Request source information. The program receives your captured draft and can inspect the project folder. After the temporary connection closes, the form shows the returned documentation.
  5. Read or select the text, then choose Close. Code examples, HTML and markdown remain literal text. There is no Apply action.

If the server returns no information, try another caret position in a new form. If the document, selection or permissions changed, capture it again. Changing server settings clears the previous output. A late worker cannot publish into an editor that has closed or been unbound.

The server must advertise hover, document open/close support and UTF-16 positions. Requests have a five-second read budget and a 65536-byte message capacity including the JSON envelope and escaped draft, with at most 4096 parser tokens. Launch and synchronous writes may complete before cancellation. This explicit workflow does not provide automatic mouse hover or persistent indexing.

Server settings store paths and ordinary arguments locally as JSON. Keep credentials out of those fields; they are not encrypted credential storage. See completion and saved server settings and document formatting.

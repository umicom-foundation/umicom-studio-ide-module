Choose where you learn and build

The lesson library contains the reading material. Your project folder contains source you edit. Studio keeps these locations separate so a lesson link never depends on the folder that launched Studio.

  1. Open Guided Learning and select Choose lesson library. Select your Umicom-Applications checkout, its Framework folder, or Framework's docs/learning folder. The chosen folder must contain the supplied welcome.html lesson.
  2. Open a lesson. Studio shows its readable local documentation. Reading a lesson does not run code.
  3. Select Create a practice project. Choose your own destination and a C console project. Existing files are not overwritten. Use Open my practice folder to resume an existing project.
  4. Edit src/main.c in Code Editor and save it.
  5. Open Build > Project Settings. Check the CMake program, compiler, source folder and build folder. Grant workspace trust only after reviewing the project; build files can run commands.
  6. Configure the project, then Build. Read Output and Problems if either operation fails. Run starts the configured executable after a successful build.
  7. To debug, configure a supported debug adapter and use a Debug build. Set a breakpoint before starting Debug. To deploy locally, select an installation destination and review the install operation.

If a lesson is missing, choose the library again. A moved or incomplete checkout is not silently replaced with a different folder. The library choice is remembered when session storage is enabled. Project files stay in the destination you select; settings and recovery state remain in private application storage.

Practise with a complete course project

Guided Learning also opens the learning practicum. Select a course, then choose a new project destination using an existing parent folder and a new folder name. Select Use this project destination to prepare the path, and Export this course project to create the files.

Export runs in the background so you can keep reading. Its result belongs to the course and path accepted when you clicked. Once it completes, select Open last exported project in the IDE. Studio receives the actual entry point and build profile; you still review trust, compiler, SDK and debugger settings before executing anything.

The Notes and Assembly stock-total courses are standalone projects. The Framework storage course additionally needs an installed Framework data SDK. Existing folders are never overwritten. If export fails, inspect any partial new folder and select another destination before retrying. Closing the practicum does not undo an accepted export; keep the application running if you want it to finish.

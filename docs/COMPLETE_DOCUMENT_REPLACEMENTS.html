Replace text across open drafts

Review Complete Set lets you inspect every proposed replacement before changing your open documents together. It uses literal text matching. For a language-aware symbol change, use Rename and observe that tool's supported scope.

  1. Open the documents to include. Pinned and untitled drafts are included; every captured draft must be writable. Close unrelated documents first.
  2. Enter the search text in Find and the replacement in Replace with. An empty replacement deletes matches. Smart case ignores ASCII letter case unless the search contains an uppercase letter.
  3. Choose Review Complete Set in the editor toolbar. Command search also offers Review Complete Replacement Set.
  4. Read the full captured and proposed text. Use Previous and Next to move through the set, and choose Mark this draft reviewed for every changed draft.
  5. Select I approve all reviewed draft changes, then choose Apply complete set. Until Apply succeeds, none of the proposed replacements changes a draft.
  6. Inspect the results and save separately. Undo in each changed document restores its captured draft; there is no project-wide Undo operation.

Close an unapplied review to leave every draft unchanged. If a captured document changes, closes, is saved, moves to another path or becomes read-only, capture a fresh set. The same applies to changed caret, selection or language. Changing the Find or Replace field after capture does not rewrite the captured proposal.

The set includes at most 64 documents, with 8 MiB per document and separate 64 MiB budgets for captured text, proposals and stored Undo preparation. Existing view and Undo limits also apply. A failed allocation or stale member refuses the whole edit. Large sets may take time to prepare.

The existing Review Open Documents action remains available for individual Apply or Skip decisions. It can keep earlier accepted edits if a later decision fails. Complete Set requires a review of every changed draft before applying them together. Neither workflow saves files automatically.
